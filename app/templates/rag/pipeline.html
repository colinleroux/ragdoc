How to read the rubric

The positive rubric scores are on a 0 to 5 scale, where 5 is the maximum and means the answer strongly meets that criterion using only the retrieved evidence.

  • Question alignment: 0-5
  • Factual correctness: 0-5
  • Groundedness: 0-5
  • Citation quality: 0-5
  • Completeness: 0-5
  • Conciseness: 0-5
  • Hallucination penalty: 0 to -5, where 0 is best and more negative is worse

A run only passes when it stays well-grounded: groundedness, factual correctness, and question alignment all need to be high, and hallucination penalty needs to stay at 0.
